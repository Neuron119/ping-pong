# PING · 指尖乒乓

无需服务器、构建工具、账号或网络的静态 3D 乒乓球游戏。竖屏优先，支持手机触屏和桌面鼠标。

## 直接打开

双击 `index.html`，使用支持 WebGL 的现代浏览器打开即可。请保留整个目录，尤其是 `assets/vendor/three.min.js`。运行时没有 CDN、字体、接口或其他外部请求。

手机系统的文件预览器通常不能运行网页脚本；手机推荐通过 GitHub Pages 或其他静态托管地址在 Safari / Chrome 中打开。桌面可直接使用 `file://`。

## 操作

- 选择正式比赛或练习模式。正式比赛可选难度、AI 打法与单局 / 三局两胜。
- 按住球场下半区任意位置拖动球拍。左右找球，前后移动调整击球位置。
- 来球在自己半台落台后，对准球路可用静止拍面借力挡回；向上挥拍加力，横向擦拍加旋。
- 轮到你发球时，球停在球拍前上方并随拍移动，向前挥拍即可发出；不用抛球、点击按钮或等待回落。
- 挥动速度、左右方向和接触位置共同决定回球力量、落点与旋转。轻推、明显减速切削和近网搓球辅助产生下旋，快速前挥产生上旋；接触瞬间向右横擦产生左侧旋，向左横擦产生右侧旋。横擦可以独立击球，球面标记显示旋转，轨迹受侧向马格努斯力影响而弯曲。
- 高度自动辅助，碰撞有适度容错。音效、触觉反馈、球迹、落点及挥拍时机提示可关闭。
- `P` 暂停；切到后台自动暂停。设置、规则及战绩窗口打开时也会暂停比赛。

## AI 接发与新增难度（1.6.0）

- 修复接发球：AI 以实际的旋转与两次落台轨迹预判拍点，短球提前上步，不再总等到球下落。接到低球或擦拍边缘时优先控制回球，避免碰到了却打出底线。
- 难度由六档增至八档。**冠军**比传奇反应更快，能更靠前接短球，仍保留少量失误；最高的**巅峰**取消随机漏接和故意打偏，回球出手前验证能否过网并安全落台，必要时减速、收角度。两档仍共用真实球拍碰撞，不会截击未落台的球；极端球可能够不到。

## 跟手与接触（1.5.2）

- 取消来球接近时的前后／左右挥拍限位，快速迎前、斜挥与横移救球持续跟手；触球后的同一次拖动、发球后的继续移动也正常响应。轻松／标准／有力档位改为调整手势力量，不再限制位置。
- 球拍碰撞改为检查球与球拍的整段相对移动，修复球先到拍面、随后横移或拍缘接触被漏判的问题。双方拍缘容错约增加 1.7 cm，保留明确偏离球拍、已经远离拍面和未落台截击的限制。
- 快速前后移动时及时重算相遇高度，避免高度辅助沿用旧站位。画质变化而球场尺寸未变时保持当前触控，防止自动降画质中断拖动。
- 默认取景拉近，分别按双方实际活动范围留白；390 px 竖屏全屏下，近端台边宽度由约 178 px 增至 211 px（约 +19%），镜头距离缩短约 14%。俯视角与已保存的高度设置继续生效，两侧救球和手指仍可操作。
- 保留连续的轻挡／主动加力／旋转与招牌动作冷却。

## 视角下调（1.5.1）

- 默认视角下调约 5°，最低视角由 30° 扩展到 18°，最高仍为 57°。设置继续使用 0–100% 高度，步进细化到 1%；推荐值仍标为 60%，对应新的较低视角，已保存的百分比继续生效。
- 保留按屏幕比例自动取景、左右边角触控留白、实时预览与恢复推荐视角。击球物理、力量和摩擦反馈沿用 1.5.0。
- 设置中的预览框跟随实际球场比例，竖屏时不再放入固定横框补两侧底色；完整画面等比显示。

## 半拟真手感与竖屏边角（1.5.0）

- 采用平衡的半拟真手感：静止拍面可借力挡回，主动挥拍明显加速；来球速度、旋转、偏心触球与胶皮摩擦共同影响出球。轻挡、轻推、快攻和横擦之间连续变化，避免力度跨过阈值时弹道突然跳变。
- 双方共用可见拍面的扫掠碰撞，减少“球没碰到拍却被接回”的情况。击球仅在接触瞬间提供过网与落点辅助，飞行中继续按重力、阻力和旋转计算；低球、擦拍边缘、强来旋仍会失误。总出球速度限制为 9.2 m/s，旋转限制为 210 rad/s，招牌球也遵守上限与原有冷却。
- 一划发球保留，增加约 65 ms 的短引拍、触球及随挥；球更贴近拍面，发球力度和旋转连续变化。AI 通过反应延迟与站位偏差形成失误，实际碰到球时仍按相同拍面判定。
- 默认视角提高，按屏幕比例为左右底角、台外救球及手指间距自动留白。设置新增 0–100% 视角高度、即时球场预览、恢复推荐值；刷新记住选择，横竖屏与全屏会重新取景。左右外侧触控平滑增加可达范围，中心操作保持直接。
- 触球反馈随实际冲击强度变化：短促碰撞声、横擦摩擦声、拍面轻微回弹与随挥、支持设备上的短震动；轻挡和重击有所区别。摩擦声为本地合成，未模拟长时间粘球。

## 招牌动作冷却（1.4.1）

- 降低正式比赛招牌动作频率：双方各自释放后，接下来完整的 2 分无法再次释放，第 3 分恢复触发资格，仍需达到原有技术条件、每分最多一次。例如第 1 分释放，第 2、3 分冷却，第 4 分才可再次触发。
- 冷却只随实际得分推进，无论哪一方得分；发球擦网重发、暂停和等待不抵扣，换局保留。新比赛重置；练习仍按每球一次供试招。

## 落点、手型与球馆更新（1.4.0）

- 斜挥直接控制左右落点，轻推短、快挥深，发球同样可变线；直推保留当前线路，修复回球总往中间集中。强旋转弹道采用更精细的落点求解。
- 重做连续表面的简洁手型：手指、手掌、手腕和前臂，不添加指甲和独立关节块。横拍三指握柄、食指贴背；直拍拇食指夹住拍颈、三指托住拍背，拍面朝向与握柄位置分别建模。左右手和对手镜像。
- 设置中新增「显示手臂」，关闭后隐藏双方手和前臂、保留球拍，刷新后记住。顶部设置改成更大的绿色文字按钮；球场上沿新增设置入口，滚动或全屏时仍可进入。
- 双方分别设置横拍／直拍、惯用手、参考底板，默认跟随选手。许昕默认为左手直拍，马龙默认为右手横拍；来源与年代见 `选手资料.html`。梁靖崑底板未确认，默认使用明确标注的自定义木纹外观。器材是风格化参考，不是精确复刻。
- 左半边来球时右手反手拍姿渐变至约 80–90°，左手和对手镜像；补上引拍、触球随挥和回位。手型始终跟随球拍。
- 十位选手放大为鲜明风格，主要优势相对普通基准约 30–45%，弱点明确、六维预算相同。移动、力量、旋转和接球范围不同，基础控制一致；AI 保留自己的落点、近台距离和节奏，也会寻找空当、追身与反向变线，短球会迎前接。
- 条件招牌动作：王楚钦「王之爆冲」、张继科「霸王拧」等。需准确触球、合适站位和足够速度；双方每分各最多一次，发球不消耗。1.4.1 起正式比赛还需经过后续两分冷却。选人卡点击技能名查看条件。成功时出现短提示、专属球迹及清脆击球声。
- 深蓝磨砂球台、台边金属结构、网夹与网绳、暖色光影；球拍补充木层、海绵和手柄配色；球体采用哑光材质、轻微接缝与印字，轮廓和球迹可关闭。

## 跟手修复（1.3.1）

- 修复来球尚远时快速拖动被误判成击球、从台外向台内移动时球拍卡住的问题。当时的短暂前伸保护仅在已落台、左右对准且即将接触时生效（1.5.0 调整为约 0.27 秒）；1.5.2 已取消移动保护，所有拖动持续跟手。
- 提高左右与前后位置跟随速度；慢速练习只减慢比赛时间，球拍的位置跟随仍保持正常响应。高度辅助继续限制升降速度与加速度，并让台边净空高度连续变化。
- 手指拖过边界后反向移动立即响应；击球保护结束后从当前位置继续拖动，避免突然追赶。松手、取消触控及重新按下清除上一段拖动的补偿。
- 保留主动挥拍、接触前稳高、旋转、双方动作与原有设置，不增加新的接球提示。

## 球体、场景与旋转更新（1.2.0）

- 球默认显示为原来的 **120%**，可在设置中调为 **100%–180%**；仅改变显示，物理碰撞仍使用相同的 40 mm 球。提供暖白、橙、荧光黄和自定义颜色，保留动态球纹和近球轮廓。
- 球拍增加木质夹层、海绵、胶皮微纹理、护边、手柄饰条与标识。经典圆拍、进攻方肩拍、日式方拍三款外形可选，胶皮有红、黑、绿、蓝及自定义颜色；装备只影响外观。
- 球拍按位置与来球平滑切换姿态：近网短球开拍搓球、按惯用手镜像正反手挡攻、高球抬拍扣杀；左右站位附带约 15° 自然侧倾。提示可关闭；1.5.0 起实际碰到静止拍面也可借力挡回。
- 旋转全部来自手势和接球动作辅助，不增加旋转按钮。快速前挥偏上旋，轻推或前挥后明显减速偏下旋，近网适度挥拍辅助搓球，大力前挥可覆盖该辅助；左右擦拍叠加侧旋。
- 空气阻力随速度平方增强，使用三轴旋转与速度叉积产生马格努斯加速度，并逐渐衰减旋转。落台使用接触点滑动速度、受限摩擦冲量和空心球转动惯量，在平动与转动间传递能量；上旋落台前更下扎、落台后更向前，强下旋更减速。为保持手机可玩性，仍有高度与过网弹道辅助。
- 手机击球时机窗口略放宽，识别接触前短时间的挥拍和减速切削；保留拍子短促震动，减轻镜头晃动。落点光圈和弧线轨迹可分别开关。
- 加入 **大师、传奇**：更早反应、预判含旋转与反弹的球路、长短调动、追身和反向变线，更强回球与旋转。两档仍保留反应、站位和落点失误；实际能力由回合验证。
- 场景增加 **户外公园、海边、屋顶球场**，连同室内共四种，可在开场面板或设置中切换。树木、海面、城市与灯光全部本地生成；没有风，场景不改变比赛物理。
- 原有设置与战绩继续使用原来的存储键。新增设置自动补全默认值，刷新仍保留选择。

## 新增体验（1.1.0）

- 手机防遮挡：触屏绝对位置控制，球拍位于手指上方，设置中可调 0–120 px 间距（默认 54 px）；鼠标保留按下即接管的相对移动。触控点有轻量标记，近球轮廓可关闭。
- 连续喂球练习：自动喂球，回到对方半台算成功，自动进入下一球。漏接也继续；显示成功、总球数和连续成功，不写入比赛战绩。
- 慢速练习：以 0.65× 时间推进，保留完整落台和旋转模拟，便于找准挥拍时机。
- 发球练习：持续练习直接挥拍发球，两侧合法落台算成功，自动准备下一球。
- AI 打法：均衡型节奏均衡；防守型回球较慢、落点较短、偏下旋；进攻型更快、更深、偏上旋并调动空当。难度仍独立控制反应和失误。
- 画质：省电（30 帧目标、无动态阴影）、均衡（60 帧目标、1024 阴影）、高清（60 帧目标、2048 阴影）。默认均衡，持续低帧率时可自动逐档降低；设置中可关闭自动降低。帧率是目标值，实际取决于设备。
- 物理固定步长独立于画面帧率；落点提示用同一套旋转积分预测。

## 碰撞音效（1.0.2）

球拍使用短促接触声与快速衰减的共鸣，落台音色更空心，触网为较轻的闷响。碰撞强度控制音量与明亮度，击球位置产生细微音色变化；左右位置控制声道，远端声音稍轻，并加入少量球馆早期反射。得分提示保持轻柔。

声音在本地合成、预生成到内存中，属于仿真音效，没有使用真人录音或在线素材。首次点击后启用声音，顶部与设置中的开关均能静音；浏览器不支持音频时仍可比赛。缓存短音色、限制同时播放数量、释放结束的节点，并对叠加音量做保护。

## 比赛与物理

发球操作按触屏体验简化为持球随拍、挥拍发出；落台与计分保留标准要求。11 分制、净胜两分、每两分换发、10 平后每分换发。发球先落己方半台，再落对方半台；合法擦网发球重发；正常擦网回球继续。未过网、出界、同侧两跳、未落台截击均会判分。三局两胜时逐局轮换首发，决胜局 5 分交换场地，镜头始终在玩家后方。

使用真实球台尺寸（2.74 × 1.525 米，台高 0.76 米，网高 0.1525 米）、重力、落台弹性、速度平方空气阻力、三轴马格努斯力、摩擦反弹与扫掠球网碰撞。回球弹道有适度净空辅助以适配触屏，属于注重可玩性的物理模拟；没有实现真人发球动作裁判、完整网布形变和完整流体动力学。

电脑难度参数在 `physics.js` 的 `LEVELS` 中：

| 难度 | 反应延迟 | 球拍速度上限 | 主动漏接概率 | 回球落点失误概率 |
| --- | --- | --- | --- | --- |
| 入门 | 290 ms | 1.65 m/s | 24% | 16% |
| 标准 | 190 ms | 2.3 m/s | 14% | 10% |
| 进阶 | 120 ms | 3 m/s | 6.5% | 5.5% |
| 专业 | 65 ms | 4.1 m/s | 2.5% | 2.5% |
| 大师 | 43 ms | 5.0 m/s | 1.2% | 1.4% |
| 传奇 | 26 ms | 6.0 m/s | 0.6% | 0.8% |
| 冠军 | 14 ms | 7.2 m/s | 0.25% | 0.3% |
| 巅峰 | 5 ms | 8.6 m/s | 0% | 0% |

这些是横移与随机失误的基础参数，不是实际失误率；角色、球速、落点、可达距离和碰撞仍会影响比赛。战绩与设置保存在当前浏览器的 `localStorage`。浏览器禁止存储时仍可玩，本次数据仅保留在页面内。震动通过浏览器 Vibration API 提供，iOS Safari 等不支持时保留视觉与音效反馈。

## GitHub Pages

1. 将本目录所有文件上传到 GitHub 仓库，确保 `index.html` 位于仓库根目录。
2. 仓库 **Settings → Pages → Build and deployment** 选择 **Deploy from a branch**。
3. 选择存放文件的分支及 **/ (root)**，保存。
4. GitHub 部署完成后，使用 Pages 地址访问。支持项目子路径，不需要修改资源链接。

更新现有网站时，解压 `work/PING-static.zip`，把解压目录内的文件及 `assets/` 覆盖上传到仓库根目录。**必须同时上传全部脚本（包含 `motion.js` 和 `view.js`）、`选手资料.html` 及整个 `assets/` 文件夹（包含 `hand-meshes.js`、装备来源与头像）**，不要只替换 `index.html` 或上传压缩包本身。提交后等待 GitHub Pages 完成发布；本次没有直接修改线上仓库。

## 检查

不需要安装依赖即可运行物理和计分检查：

```sh
node --test tests/*.test.cjs
```

已配置 Playwright 与 Chrome 的开发环境还可运行 `node tests/browser.cjs --render-stability`，检查台面不存在重叠表面，并比较首页和比赛视角的连续帧。测试脚本支持通过 `PLAYWRIGHT_PATH` 和 `CHROME_PATH` 指定安装路径。

`node tests/browser.cjs --audio` 使用浏览器原生离线音频渲染检查碰撞波形、轻重力度、远近与左右声道、静音和叠加输出，并以真实触屏事件验证游戏发声及手势恢复音频。生成的试听文件为 `work/qa/ping-audio-preview.wav`，顺序为轻击、重击、落台、触网、连续回合。

`node tests/browser.cjs --responsiveness` 使用真实触屏事件验证接触前两轴自由移动、快速迎前触球及持续移动、左右横移救球、画质切换不中断触控；加 `--release` 可检查上传包。

`node tests/browser.cjs --feel` 验证 360、390、430 宽竖屏原生全屏、所有视角的边角可达、左右反向移动、实际触屏静止挡球与主动挥拍、预览变化、恢复推荐值及刷新保存；加 `--release` 可检查上传包。

`node tests/browser.cjs --features` 验证手机直接挥拍发球、手指偏移、真实横向擦拍、练习成功与自动喂球、慢速时间、AI 打法、画质切换和多尺寸布局。

`node tests/browser.cjs --upgrade` 检查四个场景、八档难度、球大小与颜色、三款球拍、设置与已有战绩保存、手机触屏发球、实际触屏前伸搓球/左右正反手姿态和多尺寸布局。

`node tests/browser.cjs --ai` 检查竖屏／横屏／桌面的新难度入口、旧难度战绩兼容和新难度保存，以及真实触屏发球后巅峰 AI 合法回球；加 `--release` 可检查上传包。

`node tests/browser.cjs --characters` 验证 10 位角色与互斥选择、雷达图、左右手、姓名比分、战术覆盖和设置保存；通过真实触屏事件接回高度辅助下的来球，并确认升降速率与双方渲染姿态。

`node tests/browser.cjs --movement` 通过真实触屏事件验证快速从台外拖入、远处来球时不误触发击球限位、越界后反向移动以及松手重新接管。浏览器测试使用桌面 Chrome 模拟触屏；实际手机的响应仍需真机试玩确认。

`node tests/browser.cjs --portraits` 验证 10 位选手图片可离线加载、圆形裁切、角色与比分同步、手机/横屏/桌面布局、练习计数和缺图回退。

`node tests/browser.cjs --settings` 检查放大的设置入口、球场入口、手臂即时隐藏与恢复、保留球拍、暂停和刷新保存；覆盖竖屏、横屏与桌面。

`node tests/browser.cjs --grips` 渲染横拍／直拍的正背面，检查连续闭合手型和左右手、双方反手倾斜时的腕臂连接。

`node tests/browser.cjs --control` 通过实际触屏与鼠标事件验证斜挥左右发球、装备覆盖、握法和惯用手跟随、刷新保存。

`node tests/browser.cjs --identity` 使用受控合法触球场景检查招牌动作的画面提示与球迹，并在正式比赛中验证双方第 1、4、7 分触发、间隔两分回普通球及冷却说明；加 `--release` 可检查上传包内文件。这不等同于真人手势触发测试，触发难度仍需试玩确认。

## 文件

- `index.html`：中文界面与弹窗
- `styles.css`：桌面、竖屏与横屏样式
- `characters.js`：十位角色、放大的游戏风格、招牌动作及装备默认值
- `选手资料.html`：资料来源、游戏数值与设计解释
- `physics.js`：独立计分、发球、碰撞、AI 与弹道
- `game.js`：Three.js 球馆、触控、设置与战绩
- `visuals.js`：球拍、简洁握拍手型、前臂与四种场景
- `motion.js`：引拍、触球回弹、摩擦随挥与回位
- `view.js`：视角高度、屏幕安全取景和边角触控映射
- `assets/hand-meshes.js`：本地离线生成的连续手型几何数据
- `assets/equipment-sources.json`：代表装备来源、资料年代和未确认项
- `quality.js`：画质档位与持续低帧率降级策略
- `audio.js`：本地碰撞音色合成、空间声道与音频播放管理
- `assets/vendor/three.min.js`：本地 Three.js 0.160.1，MIT 许可证见同目录
- `assets/portraits/`：10 位选手圆形头像，以及原图出处与裁切记录

页面内的木地板、球网、标识等纹理均在本地用 Canvas 生成。
