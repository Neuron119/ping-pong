# PING · 指尖乒乓

无需服务器、构建工具、账号或网络的静态 3D 乒乓球游戏。竖屏优先，支持手机触屏和桌面鼠标。

## 直接打开

双击 `index.html`，使用支持 WebGL 的现代浏览器打开即可。请保留整个目录，尤其是 `assets/vendor/three.min.js`。运行时没有 CDN、字体、接口或其他外部请求。

手机系统的文件预览器通常不能运行网页脚本；手机推荐通过 GitHub Pages 或其他静态托管地址在 Safari / Chrome 中打开。桌面可直接使用 `file://`。

## 操作

- 选择正式比赛或练习模式。正式比赛可选难度、AI 打法与单局 / 三局两胜。
- 按住球场下半区任意位置拖动球拍。左右找球，前后移动调整击球位置。
- 来球在自己半台落台后，向上快速挥动手指或鼠标。球拍静止不会自动接球。
- 轮到你发球时，球停在球拍前上方并随拍移动，向前挥拍即可发出；不用抛球、点击按钮或等待回落。
- 挥动速度、左右方向和接触位置共同决定回球力量、落点与轻量旋转。慢推产生下旋，快速前挥产生上旋；接触瞬间向右横擦产生左侧旋，向左横擦产生右侧旋。横擦可以独立击球，球面条纹显示旋转，轨迹受侧向马格努斯力影响而弯曲。
- 高度自动辅助，碰撞有适度容错。音效、触觉反馈、球迹、落点及挥拍时机提示可关闭。
- `P` 暂停；切到后台自动暂停。设置、规则及战绩窗口打开时也会暂停比赛。

## 新增体验（1.1.0）

- 手机防遮挡：触屏绝对位置控制，球拍位于手指上方，设置中可调 0–120 px 间距（默认 54 px）；鼠标保留按下即接管的相对移动。触控点有轻量标记，近球轮廓可关闭。
- 连续喂球练习：自动喂球，回到对方半台算成功，自动进入下一球。漏接也继续；显示成功、总球数和连续成功，不写入比赛战绩。
- 慢速练习：以 0.65× 时间推进，保留完整落台和旋转模拟，便于找准挥拍时机。
- 发球练习：持续练习直接挥拍发球，两侧合法落台算成功，自动准备下一球。
- AI 打法：均衡型节奏均衡；防守型回球较慢、落点较短、偏下旋；进攻型更快、更深、偏上旋并调动空当。难度仍独立控制反应和失误。
- 画质：省电（30 帧目标、无动态阴影）、均衡（60 帧目标、1024 阴影）、高清（60 帧目标、2048 阴影）。默认均衡，持续低帧率时可自动逐档降低；设置中可关闭自动降低。帧率是目标值，实际取决于设备。
- 物理固定步长独立于画面帧率；落点提示用同一套旋转积分预测。

## 碰撞音效（1.0.2）

球拍使用短促接触声与快速衰减的共鸣，落台音色更空心，触网为较轻的闷响。碰撞强度控制音量与明亮度，击球位置产生细微音色变化；左右位置控制声道，远端声音稍轻，并加入少量球馆早期反射。得分提示保持轻柔。

声音在本地合成、预生成到内存中，属于仿真音效，没有使用真人录音或在线素材。首次点击后启用声音，顶部与设置中的开关均能静音；浏览器不支持音频时仍可比赛。缓存短音色、限制同时播放数量、释放结束的节点，并对叠加音量做保护。

## 比赛与物理

发球操作按触屏体验简化为持球随拍、挥拍发出；落台与计分保留标准要求。11 分制、净胜两分、每两分换发、10 平后每分换发。发球先落己方半台，再落对方半台；合法擦网发球重发；正常擦网回球继续。未过网、出界、同侧两跳、未落台截击均会判分。三局两胜时逐局轮换首发，决胜局 5 分交换场地，镜头始终在玩家后方。

使用真实球台尺寸（2.74 × 1.525 米，台高 0.76 米，网高 0.1525 米）、重力、落台弹性、空气阻力、轻量旋转与扫掠球网碰撞。回球弹道有适度净空辅助以适配触屏，属于注重可玩性的物理模拟；没有实现真人发球动作裁判、擦边侧面和完整流体动力学。

电脑难度参数在 `physics.js` 的 `LEVELS` 中：

| 难度 | 反应延迟 | 球拍速度上限 | 主动漏接概率 | 回球落点失误概率 |
| --- | --- | --- | --- | --- |
| 入门 | 290 ms | 1.65 m/s | 24% | 16% |
| 标准 | 190 ms | 2.3 m/s | 14% | 10% |
| 进阶 | 120 ms | 3 m/s | 6.5% | 5.5% |
| 专业 | 65 ms | 3.9 m/s | 2.5% | 2.5% |

这些是每次决策的参数；实际接球率还受球速、落点、球拍移动距离和碰撞影响。战绩与设置保存在当前浏览器的 `localStorage`。浏览器禁止存储时仍可玩，本次数据仅保留在页面内。震动通过浏览器 Vibration API 提供，iOS Safari 等不支持时保留视觉与音效反馈。

## GitHub Pages

1. 将本目录所有文件上传到 GitHub 仓库，确保 `index.html` 位于仓库根目录。
2. 仓库 **Settings → Pages → Build and deployment** 选择 **Deploy from a branch**。
3. 选择存放文件的分支及 **/ (root)**，保存。
4. GitHub 部署完成后，使用 Pages 地址访问。支持项目子路径，不需要修改资源链接。

当前版本只制作本地文件，尚未连接或推送任何 GitHub 仓库。

## 检查

不需要安装依赖即可运行物理和计分检查：

```sh
node --test tests/physics.test.cjs tests/quality.test.cjs
```

已配置 Playwright 与 Chrome 的开发环境还可运行 `node tests/browser.cjs --render-stability`，检查台面不存在重叠表面，并比较首页和比赛视角的连续帧。测试脚本支持通过 `PLAYWRIGHT_PATH` 和 `CHROME_PATH` 指定安装路径。

`node tests/browser.cjs --audio` 使用浏览器原生离线音频渲染检查碰撞波形、轻重力度、远近与左右声道、静音和叠加输出，并以真实触屏事件验证游戏发声及手势恢复音频。生成的试听文件为 `work/qa/ping-audio-preview.wav`，顺序为轻击、重击、落台、触网、连续回合。

`node tests/browser.cjs --features` 验证手机直接挥拍发球、手指偏移、真实横向擦拍、练习成功与自动喂球、慢速时间、AI 打法、画质切换和多尺寸布局。

## 文件

- `index.html`：中文界面与弹窗
- `styles.css`：桌面、竖屏与横屏样式
- `physics.js`：独立计分、发球、碰撞、AI 与弹道
- `game.js`：Three.js 球馆、触控、设置与战绩
- `quality.js`：画质档位与持续低帧率降级策略
- `audio.js`：本地碰撞音色合成、空间声道与音频播放管理
- `assets/vendor/three.min.js`：本地 Three.js 0.160.1，MIT 许可证见同目录

页面内的木地板、球网、标识等纹理均在本地用 Canvas 生成。
